# 아침 경제 브리핑

매일 아침 경제 지표와 주요 뉴스를 한 화면에 모아 보는 모바일웹(PWA). AI·유료 API 없이 무료로 동작합니다.

## 화면
1. **많이 보도된 뉴스 TOP 3**: 여러 언론사가 함께 다룬 기사 순
2. **시장 지표**
   - 필수: 원/달러, 코스피, S&P 500, 나스닥, 미 국채 10년, WTI, 한국 기준금리
   - 더보기: 코스닥, 다우, 원/엔(100엔), 원/위안, 금, 달러인덱스, VIX, 비트코인, 국고채 3년
   - 전일 대비 ▲▼(상승 빨강, 하락 파랑), 7일 미니 그래프, 크게 움직인 지표는 테두리로 강조
3. **분야별 헤드라인**: 거시·금리 / 증시 / 부동산 / 산업·기업 / 해외, 분야마다 5건과 원문 링크
4. **일정**: 오늘 일정은 맨 위 배지로, 2주 안의 일정은 목록으로 (`config/events.json`)

## 기사 고르는 규칙
- 최근 20시간 기사만 사용
- 제목이 비슷한 기사는 하나로 묶고, 몇 개 언론사가 다뤘는지 셈
- 다룬 언론사 수 → 같은 기사 묶인 수 → 최신 순으로 정렬
- 포토·부고·인사·운세 같은 기사는 제외 (`scripts/collect.mjs`의 `NOISE`)

## 구조
```
scripts/collect.mjs   지표·뉴스 수집 → public/data/YYYY-MM-DD.json, latest.json, index.json
public/               정적 화면 (index.html, app.js, style.css, sw.js, manifest)
.github/workflows/daily.yml   매일 06:00 KST 자동 실행 + GitHub Pages 배포
```

## 로컬 실행
```bash
npm run collect     # 오늘 데이터 수집
npm run serve       # http://localhost:5178
```
설치할 패키지가 없습니다 (Node 20 이상만 있으면 됨).

## 설정 (선택)
| 환경변수 | 설명 |
|---|---|
| `ECOS_API_KEY` | 한국은행 ECOS 키(무료 발급). 없으면 공개 sample 키로 최근 값만 조회. 키가 있으면 기준금리 "최근 변경일"까지 표시 |

## 주의
- 기사는 제목·링크·언론사·시각만 저장합니다. 본문은 저장하지 않습니다.
- `config/events.json`의 금통위·FOMC 일정은 매년 초 공식 일정을 보고 갱신하세요.
